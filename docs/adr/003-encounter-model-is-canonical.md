# ADR-003: Encounter Model JSON is canonical; C# emitted per flavor profile

**Status:** Proposed
**Date:** 2026-09-18

## Context
awgil/ffxiv_bossmod (`vbm`) and FFXIV-CombatReborn/BossmodReborn (`bmr`) differ in `StateMachineBuilder` and component signatures (enum-typed vs `uint` action ids, constructor shapes), and both change over time. Users also need to hand-correct inferences without redoing analysis.

## Decision
A versioned Encounter Model JSON (identity, participants, abilities with shape/mechanic/confidence/evidence, timeline, arena, components, review items, overrides) is the single source of truth. C# is generated by `StringBuilder` templates driven by a flavor profile JSON pinned to an upstream commit. Hand edits live in an `overrides` block merged three-way (inferred / overrides / effective).

## Consequences
- Re-emit without re-analysis; switching flavor is a flag.
- LLM polish edits data, never code.
- `forge diff` is required to warn when someone edits the generated C# directly.

## Alternatives rejected
- **Emit C# directly from analysis** — every correction forces a full re-analysis.
- **Runtime-interpreted module format** — upstream has no module-pack loading yet; would require a BossMod fork.
