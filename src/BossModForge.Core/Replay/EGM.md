# Replay

## Overview
Parses BossMod replay recordings (text `.log`, binary `BLOG`, Brotli-compressed binary `BLCB`) into an immutable list of typed `Op` records plus per-actor timelines. `ReplayParser` detects the encoding and wraps the stream in an `IReplayInput` (`TextInput` / `BinaryInput`); `OpReader` dispatches each tag to a version-gated payload reader; `Recording` aggregates ops, issues, tag counts and `ActorTimeline`s. Op record types live in `Op.cs`, `Ops.World.cs`, `Ops.Actor.cs`, `Ops.Party.cs`; value types and enums in `Primitives.cs`; four-char tag constants in `Tag.cs`.

- Op hierarchy: `abstract record Op(DateTime Timestamp)` with virtual `Tag`; `RawOp(Timestamp, RawTag, ImmutableArray<string> Fields)`, `OpaqueOp(Timestamp, OpaqueTag)` [Op.cs:Op, Op.cs:RawOp, Op.cs:OpaqueOp]

## Invariants
- `Tag.Parse` throws `ArgumentException` unless the string has exactly 4 characters; tag value is the little-endian `uint` of the 4 ASCII bytes [Tag.cs:Tag.Parse, Tag.cs:Tag(ReadOnlySpan<byte>)].
- Op `Tag` is computed from payload where one record covers several tags: `WaymarkOp` (WAY+/WAY- by `Position`), `ActorTargetableOp`/`ActorDeadOp`/`ActorCombatOp` (+/- by `Value`), `ActorTetherOp` (TET- when both ids are 0, else TETH), `ActorStatusOp` (STA-/STA!/STA+), `ActorIncomingEffectOp` (AIE+/AIE-); `OpReader` overrides `Tag` via `init` for on-disk tags (e.g. PAR+, PAR!, TET+) [Ops.World.cs:WaymarkOp, Ops.Actor.cs:ActorTetherOp, Ops.Actor.cs:ActorStatusOp, OpReader.cs:OpReader.ParseTether, OpReader.cs:OpReader.ParsePartyModify].
- `ActionId.Raw = (type << 24) | id`; `Id` is the low 24 bits [Primitives.cs:ActionId].
- `ActionEffects.From` always produces an array of exactly 8 ulongs (excess input truncated, missing zero-filled); equality and hash treat default/empty `Raw` as `Empty` [Primitives.cs:ActionEffects.From, Primitives.cs:ActionEffects.Equals].
- `ParseInput` stops with an `UnsupportedVersion` `Error` issue and returns zero ops when header version < 10; header version > 31 is parsed with v31 gates and flagged `Degraded` once [OpReader.cs:OpReader.ParseVersion, ReplayParser.cs:ReplayParser.ParseInput].
- `Recording.Degraded` is true iff some issue has `IssueSeverity.Degraded`; `End` is the last op's timestamp or `Meta.StartTime` when no ops [Recording.cs:Recording.Recording].
- Text streams passed to `ReplayParser.Parse(Stream, …)` must be seekable (throws `ArgumentException` otherwise); stream is rewound to position 0 for text [ReplayParser.cs:ReplayParser.Parse].
- `ParseInput` also emits `OlderVersion` (Warning, once on the `VER` tag when `reader.Version < 23`) and `LineageDetected` (Info, once, after the first op once `reader.LineageDetected` is true) [ReplayParser.cs:ReplayParser.ParseInput].
- Many tags are consumed (payload read exactly) into payload-less `OpaqueOp`: `CLAR`, `CLRJ`, `CDN±`, `CLAL`, `CLMV`, `CLCB`, `CLST`, `CLCD`, `CLDA`, `CLBH`, `CBLU`, `CLVL`, `CLAF`, `CPET`, `CLFT`, `CLFD`, `CLKV`, `FATE`, `DDPG`, `DDMP`, `DDPT`, `DDIT`, `DDCT`, `DDMG`, `IPCI`, `IPCS`, `IPCX`, `PVP±`, `FLY±`, `SGN±`, `ARO±`, `VFX`, `PATS`, `HATE` and the `R*` replay tags (`RTT`, `RPRE`, `RMOD`, `RROL`, `RMOV`, `RACT`, `RPRI`), among others [OpReader.cs:OpReader.BuildDispatch, OpReader.cs:OpReader.Opaque].
- Opaque-tag payload gates: `DDPG` extra bool v≥29; `CHOC` extra bool v≥30; `DDMP` raw bytes v<23, else per-room flags (ushort v≥29, byte v23–28); `CLDA` slot-count layout v≥25, else two slots with extra bytes v≥20; `CLAF` progress/hand-in bytes v≥27 [OpReader.cs:OpReader.ParseDeepDungeonMap, OpReader.cs:OpReader.ParseClientDutyActions, OpReader.cs:OpReader.ParseClientActiveFate].
- Unknown tags: in text, become `RawOp` plus one `UnknownTag` Info issue per distinct tag; in binary, parsing stops with `UnknownBinaryTag` `Degraded` issue [ReplayParser.cs:ReplayParser.ParseInput]. Parse exceptions (`FormatException`, `OverflowException`, `ArgumentException`, `EndOfStreamException`, `InvalidOperationException`, `IndexOutOfRangeException`) become `MalformedLine` Warning (text, continues) or `UnknownBinaryTag` Degraded (binary, stops) [ReplayParser.cs:ReplayParser.ParseInput].
- `RawOp` is counted in `TagCounts` but omitted from `Recording.Ops` when `ParseOptions.KeepRawOps` is false [ReplayParser.cs:ReplayParser.AddOp].
- Binary timestamps derive from QPC: first `FRAM` sets time to `StartTime`; later frames add `(qpc - qpcStart) * TicksPerSecond / Qpf` ticks (when `Qpf != 0`); text timestamps come from each line's first `|` field [OpReader.cs:OpReader.ParseFrameStart, OpReader.cs:OpReader.Timestamp].
- Payload layout is version-gated in `OpReader` (e.g. `ZONE` CfcId v≥13, `ACT+` LayoutId v≥26, `HpMp.MaxMp` v≥24 else 10000, `PAR` name read only for 15≤v<31, `FRAM` gauge-high v≥18) [OpReader.cs:OpReader.ParseActorCreate, OpReader.cs:OpReader.ReadHpMp, OpReader.cs:OpReader.ParsePartyModify, OpReader.cs:OpReader.ParseFrameStart].
- `Lineage` for `ACT+` v≥27: `Bmr` reads an extra `Renderflags` int; `Auto` detects from field presence (text) or by peeking 8 bytes for known tags (binary) and is left unlocked if undecidable; `CLAF` objective-npc uint gate is v29 for `Bmr`, else v28 [OpReader.cs:OpReader.ResolveActorCreateLineage, OpReader.cs:OpReader.ParseClientActiveFate].
- Text line handling: empty lines and lines starting with `#` skipped; lines with <2 `|` fields, non-4-char tag, or unparsable timestamp yield a `MalformedLine` Warning via `TakeMalformed` and `NextEntry` returns default tag [TextInput.cs:TextInput.NextEntry]. Parser loop ends when `NextEntry` returns tag value 0 (EOF) [ReplayParser.cs:ReplayParser.ParseInput].
- `BinaryInput.Peek` throws `ArgumentOutOfRangeException` for `dest.Length > 16`; its internal stream is forward-only (`Seek`, `SetLength`, `Write`, `Position` set throw `NotSupportedException`); `NextEntry` returns default on `EndOfStreamException` [BinaryInput.cs:BinaryInput.LookaheadStream, BinaryInput.cs:BinaryInput.NextEntry].
- `BinaryInput.ReadRemainingFields` returns empty and `CanRead()` is always true; `TextInput.CanRead()` is true only while fields remain on the line [BinaryInput.cs:BinaryInput, TextInput.cs:TextInput.CanRead].
- `ActorTimeline`: `Destroyed` set once (first destroy wins); `IsAliveAt(t)` ⇔ `Created <= t && (Destroyed is null || t < Destroyed)`; `PosRotAt`/`IsTargetableAt` return first sample for times before the first sample, `IsDeadAt` returns false before the first sample; sample lookup assumes samples appended in non-decreasing time order (linear scan stops at first later sample) [ActorTimeline.cs:ActorTimeline.Destroy, ActorTimeline.cs:ActorTimeline.At].
- `Recording.BuildActors`: each `ActorCreateOp` starts a new timeline (incarnation = prior count for that InstanceId) and replaces the live entry; mutation ops for an InstanceId with no live timeline are ignored [Recording.cs:Recording.BuildActors].
- `Recording.ActorAt` returns the last timeline in `Actors` with matching id alive at `t`, else null [Recording.cs:Recording.ActorAt].
- `Recording.Concat` throws `ArgumentNullException` on null and `ArgumentException` on empty list; Version = max, StartTime = min, `Qpf` and `Encoding` from first, `GameVersion` = first non-empty, `Path` = all input paths joined with `+`; issues are concatenated in input order, `TagCounts` are summed per tag, actors rebuilt from concatenated ops [Recording.cs:Recording.Concat].
- `RecordingNames.CountFor` returns 0 for a duty name that normalizes to empty; `ZoneOf` returns null when filename does not match the pattern [RecordingNames.cs:RecordingNames].
- `OpReader.ReadKnown` indexes `_dispatch[tag.Value]` directly; callers must check `IsKnown` first [OpReader.cs:OpReader.ReadKnown].

## Side Effects
- Disk read: `ReplayParser.Parse(string path, …)` opens the file with `FileMode.Open`, `FileAccess.Read`, `FileShare.Read` and disposes it on return [ReplayParser.cs:ReplayParser.Parse].
- Stream consumption: reads the first 4 bytes of the supplied stream, may set `stream.Position = 0` (text), wraps in `BrotliStream` for BLCB; disposes the input and decompression stream on completion, leaves the caller's stream open (`leaveOpen: true`) [ReplayParser.cs:ReplayParser.Parse].
- `TextInput.Dispose` disposes its `StreamReader`, which (with `leaveOpen` = true default) leaves the underlying stream open; `BinaryInput.Dispose` disposes its `BinaryReader` (inner stream disposed only if `leaveOpen` false) [TextInput.cs:TextInput.Dispose, BinaryInput.cs:BinaryInput.Dispose].
- Progress callbacks: `ParseOptions.Progress.Report` every 1024 ops when stream is seekable with nonzero length, and `Report(1f)` at end of loop [ReplayParser.cs:ReplayParser.ParseInput].
- Cancellation: `ct.ThrowIfCancellationRequested()` each loop iteration [ReplayParser.cs:ReplayParser.ParseInput].
- `OpReader` mutates its own state (`Version`, `Qpf`, `GameVersion`, `StartTime`, `Lineage`, current timestamp, QPC base) while reading; `TextInput`/`BinaryInput` hold mutable cursor state [OpReader.cs:OpReader, TextInput.cs:TextInput].
- Static state: `Tag` constants and `ReplayParser` magic values are static readonly; `RecordingNames` uses a generated static regex; no other static mutable state [Tag.cs:Tag, ReplayParser.cs:ReplayParser, RecordingNames.cs:RecordingNames].
- No network access, no file writes, no locks [all files].
